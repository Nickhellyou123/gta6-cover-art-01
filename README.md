Palm Neon Cover Studio — an offline web app that turns any photo and a caption into GTA 6-style cover art, exported as a PNG to share. Four multi-panel layouts (hero + 3, 4-grid, full bleed, tilted snapshots), four gradient-map grades (sunset, neon, teal/pink, mono), bold Anton title lettering with a Pacifico subtitle, grain and vignette, per-panel crop and position, and one-step PNG export in 1080 x 1080, 1080 x 1350 and 1920 x 1080. Photos never leave the machine; no Rockstar logos, artwork or fonts anywhere — all lettering is Anton and Pacifico under the SIL Open Font License.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
